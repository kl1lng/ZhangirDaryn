# Microsoft Rocketbox avatar

- Models: `rocketbox-male-adult-01.glb` and `rocketbox-male-adult-02.glb`
- Source models: `Male_Adult_01.fbx` and `Male_Adult_02.fbx` from [Microsoft-Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)
- Source previews and original textures: `Assets/Avatars/Adults/Male_Adult_01/` and `Assets/Avatars/Adults/Male_Adult_02/`
- Model library license: [MIT](https://github.com/microsoft/Microsoft-Rocketbox/blob/master/LICENSE.md)
- Conversion: FBX2glTF 0.9.7-p1, [BSD-3-Clause](https://github.com/facebookincubator/FBX2glTF/blob/master/LICENSE)
- Preparation: converted to binary glTF; source color and normal textures resized to 2048px and JPEG-compressed for browser delivery. Skeleton, skinning, and finger bones are retained.

The original Rocketbox asset is a fully rigged human avatar. This converted file is provided for local browser use. See the upstream project for the library paper and research citation.
