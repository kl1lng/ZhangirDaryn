# DosYm PWA

Отдельный адаптивный Next.js-клиент для публичного словаря жестов, 3D-аватара, загрузок и модерации. Существующий Streamlit-инструмент автора не заменяется.

## Локальный запуск в Windows

Из корня репозитория один раз подготовьте изолированные окружения:

```powershell
python -m venv .venv-pwa
.venv-pwa\Scripts\python.exe -m pip install -r backend\requirements.txt
Push-Location pwa
npm ci
Pop-Location
```

TensorFlow отдельно (не обязателен для интерфейса и очереди; используйте Python 3.12):

```powershell
python -m venv .venv-train
.venv-train\Scripts\python.exe -m pip install -r backend\requirements-training.txt
```

Запустить PWA, Python API/обработчик и отдельного тренера:

```powershell
.\scripts\start-pwa.ps1 -WithTraining
```

Откройте <http://127.0.0.1:3000>. Кнопки «Проверить как участник» и «Проверить как модератор» включены только в loopback-режиме для разработки. Они не являются настоящими аккаунтами Google. Для остановки только процессов, которые запустил скрипт:

```powershell
.\scripts\stop-pwa.ps1
```

Для сравнения поведения с оптимизированной production-сборкой используйте
`./scripts/start-pwa.ps1 -UseGoogle -Production`. Она собирается отдельно в
`pwa/.next-performance` и открывается на <http://127.0.0.1:3001>; текущая
dev-сессия на порту 3000 продолжает работать. Остановка запущенных сервисов —
той же командой `./scripts/stop-pwa.ps1`.

Чтобы снять локальные метрики первого экрана, простоя и фактического жеста,
выполните из `pwa/` `npm run profile:performance`. Можно задать
`DOSYM_PROFILE_URL` и `DOSYM_PROFILE_PHRASE`. JSON-отчёт сохраняется в
игнорируемую `data/pwa/performance/`; сценарий открывает временный браузер без
пользовательской сессии и использует публичный клип.

Для настоящего локального входа через Google используйте `backend/.env.local` с `DOSYM_AUTH_PROVIDER=google` и запускайте `.\scripts\start-pwa.ps1 -UseGoogle`. Обычный запуск включает локальные тестовые роли. После изменения `.env.local` перезапустите backend, чтобы он перечитал конфигурацию. Google-вход доступен только аккаунтам из списка Test users, пока приложение в статусе Testing.

Без установки TensorFlow достаточно запустить `start-pwa.ps1` без `-WithTraining`; кандидат обучения останется в очереди ожидания. Данные и видео локального демо находятся в игнорируемой Git папке `data/pwa/`. Не помещайте реальные пользовательские данные в демонстрационную базу.

## Проверки и сборка

```powershell
Push-Location pwa
npm run typecheck
npm test
npm run build
Pop-Location
.venv-pwa\Scripts\python.exe -m unittest discover -s tests
npm test
```

`npm test` внутри `pwa/` запускает проверки политики офлайна и Playwright в Microsoft Edge. Python-команды используют изолированное окружение `.venv-pwa`. Полная сборка воспроизводит локальные ресурсы аватара из `web/avatar.html`, `web/rig-motion.mjs`, GLB и установленного Three.js; не редактируйте сгенерированную папку `pwa/public/avatar/`.

## Настройки

Основной язык PWA — қазақша; русский и English выбираются в верхней панели.
Выбор сохраняется в браузере и действует офлайн. Переводчик и словарь принимают
казахскую кириллицу и латиницу, включая диакритику и обычный ASCII-ввод.
Правила для будущих слов и букв, неоднозначности и источники:
`docs/LOCALES_AND_SEARCH.md`.

Готовые жесты исходного Streamlit не появляются в отдельной PWA-базе автоматически.
Для выбранных клипов используйте явный перенос координат: `docs/IMPORT_MOTION.md`.
«сәлем» уже перенесён и проверен локально.

Примеры переменных есть в `pwa/.env.example` и `backend/.env.example`. Локальный скрипт по умолчанию использует SQLite, локальные видео и тестовые роли. Вход настраивается в backend через `DOSYM_AUTH_PROVIDER=supabase` или `google`; обе ветки используют одну PWA кнопку. Google OAuth вход не предоставляет доступ к Drive — эти учётные данные отдельные. Переменные в `.env.local` не коммитить. Адрес первого модератора записан только в локальном игнорируемом `data/pwa/private-settings.json`; файл не включать в GitHub.

Перед публичным запуском следуйте `docs/DEPLOYMENT.md`: нужны настоящие OAuth-настройки, постоянный PostgreSQL, Drive OAuth/папка, HTTPS Python-сервис и отдельный тренер. Эти внешние сервисы в этом локальном этапе не подключены.

## Состояние

Реализованы локальные сценарии тестовых ролей и прямой Google OAuth, загрузки, ожидания/решения модерации, извлечения MediaPipe из исходного конвейера, хранения координат отдельно от видео, публичного аватара, офлайн-пакетов, отзыва материала и фонового кандидата модели. Google OAuth client создан для локального callback, аккаунт владельца добавлен как Test user; локальный вход проверен в браузере и назначил модераторскую роль из серверной настройки. Google Drive API, реальный PostgreSQL и развертывание на Vercel требуют отдельных подключений и проверок. Кандидат модели не публикуется автоматически в работающий распознаватель; порог и процедура выпуска ещё не заданы.
