# Модель распознавания слов по камере

Режим «Камера» использует маленькую нейросеть (540 слов), обученную на кистях рук из датасета Slovo
(русский жестовый язык, лицензия CC BY-SA 4.0, см. `pwa/public/rsl/ATTRIBUTION.md`). Подписи классов переведены на казахский
(`scripts/slovo_kk_words.txt`). Распознавание идёт целиком в браузере, видео никуда не отправляется.

## Качество (исполнители, которых модель не видела)
| Метод | Слово первым | Среди 5 первых |
|---|---|---|
| Прежний алгоритм (1 образец на слово, 1000 слов) | 5,0% | 12,0% |
| Нейросеть, 540 слов, нарезанные клипы | 39,7% | 67,3% |
| Та же, переобученная на «живых» окнах (обрезка, лишние неподвижные кадры, пониженная частота кадров) | 37,0% | 65,2% |

Цифры измерены на готовых нарезанных видео Slovo; на живой камере, без нарезки по границам жеста, будет ниже.
Камера всегда показывает три лучших догадки, пока видны руки; слабые (уверенность ниже 0,4 или нет повторения 2 из 3) показываются пунктиром. Страница `/camera?debug=1` выводит диагностику: частоту кадров, число кадров в окне, лучшие догадки с процентами, размер кадра.
Модель распознаёт жесты РЖЯ: казахские жесты, которые отличаются, будут сопоставлены с ближайшим похожим словом.

## Как пересобрать
```bash
.venv-pwa/Scripts/python.exe scripts/slovo_handset.py          # data/slovo/handset.npz из сжатых координат Slovo
.venv-pwa/Scripts/python.exe scripts/camera_train.py           # проверка на новых исполнителях
.venv-pwa/Scripts/python.exe scripts/camera_train.py --final   # итоговая модель в web/camera-model/model.{json,bin}
```
Признаки в `scripts/camera_train.py` и `pwa/lib/camera-classifier.ts` должны совпадать; это проверяет
`pwa/tests/camera-classifier.test.ts` (фикстуры из Python).
