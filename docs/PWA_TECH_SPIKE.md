# DosYm PWA: техническая проверка

Дата реализации: 29 октября 2026 года. Это локальный стенд, не облачный пилот.

## Исходный проект

Перед изменениями проверены карта проекта и существующие API, motion SQLite, обучение и браузерный аватар. Исходный набор тестов прошёл: 35 JS и 68 Python тестов. Python 3.14 доступен для основного проекта, Node.js 24/npm 11 — для UI; TensorFlow 2.21 установлен в изолированном Python 3.12 окружении, потому что доступный Python 3.14 не имел нужного совместимого TensorFlow wheel.

Сохранён существующий Streamlit и motion/avatar код. В публичном контуре MediaPipe конвейер из `src.motion_db` запускается обработчиком; небольшой временный SQLite используется как адаптер, чтобы не создать второй вариант извлечения landmarks. Новые массивы — сжатый NumPy float32 payload с метаданными и SHA-256, без pickle, сохраняются независимо от видео.

## Выбранная техническая основа

- Next.js 16.4.3, React 19.3.1, TypeScript, custom CSS and service worker — `pwa/`.
- Python FastAPI API/worker: SQLite + локальные файлы в разработке; PostgreSQL и Drive адаптеры реализованы, но внешне не проверялись.
- Supabase Auth token validation; профиль и роль проверяются backend. Local identities доступны только явно включённым loopback demo.
- Явные разрешения на публичную обработку/показ, обучение и research фиксируются раздельными полями; обучение и research по умолчанию выключены.
- MediaPipe extraction из исходного проекта; TensorFlow trainer создаёт отдельный checkpoint-кандидат, не меняя авторские `models/`.
- Локальные ресурсы Three.js/аватара генерируются из основного источника сборочным скриптом. Размещение видео и массивов не проходит через Vercel Functions.

## Проверенные локальные сценарии

- Модерация пользователя и автоматическая очередь одобренной загрузки модератора; проверка роли и диапазонов билета.
- Загрузка MP4, валидация декодирования, прямой HTTP range-preview, исходный видеофайл остаётся при ошибке трекинга.
- Рендер реального Rocketbox аватара и локальные офлайн-пакеты только публичных выбранных жестов; запрет на приватные API/токены в service worker cache.
- Материал можно отозвать из публичного каталога и будущих снимков обучения, сохранив архивный массив; отозванные running jobs не могут записать результат.
- Локальный тренер TensorFlow действительно обучил синтетическую двухклассовую выборку в временной папке и создал checkpoint-кандидат, не затронув модели автора. Метрика синтетического smoke-test не оценивает распознавание жестов.
- Настоящая техническая сцена ширины 320, 390, 768, 1440 px проверяется headless Edge; сценарии также включают 390 px и гостевой/модераторский доступ.

## Непроверенные допущения и ограничения

Google login и Drive не настроены; локальные роли — фиктивные тестовые личности. PostgreSQL migration, Drive resumable upload/quotas, серверный Google refresh token, настоящий PWA install на iOS/Android, сеть deployment и DNS/HTTPS не проверены. Внешние сервисы не изменялись.

Пользовательское видео останется на диске/Drive до отдельного удаления. Координаты хранят движение из текущей модели landmarks и не восстанавливают детали, которых трекер не сохранил. Технически обучаемый checkpoint ещё не означает надёжный переводчик КЖЯ. Активный production registry, независимая оценка качества кандидата и rollback — будущая работа.
