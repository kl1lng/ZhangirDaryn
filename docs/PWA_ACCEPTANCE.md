# PWA: локальная приёмка

## Пройдено в локальном окружении

| Сценарий | Проверка |
|---|---|
| Гость и роли | Гость не может загрузить; пользователь не видит модерацию; тестовые роли доступны только с loopback origin/host. |
| Загрузка | Видео передаётся напрямую частями Python service, не через Vercel proxy; есть идемпотентный upload ticket, сервер проверяет файл и реальный decode. |
| Модерация | Обычная запись pending; одобрение требует revision; повторное/конкурентное решение не дублирует extraction job. |
| Ошибка модели | Непригодное видео получает безопасное сообщение, повтор доступен, видео не удаляется. |
| Координаты | Артефакт проверяет dtype/shape/finiteness/checksum; source deletion отделено и не каскадит массив. |
| Withdrawal | Скрывает материал от новых просмотров и обучения; отменяет активную запись работника по lease, исходник и координаты сохраняются. |
| Согласие | Разрешение на обучение и на исследования хранятся независимо, оба выключены по умолчанию; полный отзыв материала выключает оба. Research export и выборочный отзыв одного разрешения требуют следующей реализации. |
| Публичный каталог | Только approved+ready жесты; массивы отдельно от каталога и идут напрямую на API-домен. |
| Офлайн | Только явные публичные пакеты и статическая офлайн-оболочка; персональные видео, API-ответы и токены не кэшируются. Изменения версии удаляют только отозванные/несовпадающие записи при доступном интернете. |
| Адаптивность | Playwright на узких/широких viewport; headless screenshot/error/overflow inspection на 320/390/768/1440 px. Это не замена реального пользовательского теста. |
| ML runtime | Синтетический TensorFlow smoke-test успешно создал временную модель-кандидат; реальная точность жестов не оценивалась. |

Запуск проверок из корня:

```powershell
Push-Location pwa
npm run typecheck
npm test
npm run build
Pop-Location
.venv-pwa\Scripts\python.exe -m unittest discover -s tests
npm test
```

## Приёмка перед открытием пользователям

- [ ] Google OAuth production callback, роль первого модератора по проверенному аккаунту, logout/refresh/отмена входа на staging.
- [ ] Реальная Drive resumable загрузка, перебой в середине, потерянное подтверждение финальной части, исчерпание квоты, отзыв токена и проверка удаления/права доступа.
- [ ] PostgreSQL/Supabase миграция и изоляция данных на отдельном staging; проверка восстановления БД и артефакта из backup.
- [ ] Разделение модераторских ролей по подтверждённым аккаунтам, аудит и политика удаления/отзыва данных по требованиям страны/участника.
- [ ] Прочитать и проверить пользовательское уведомление, исследовательский scope, сроки хранения и участие учеников/несовершеннолетних с администрацией школы до сбора данных.
- [ ] Реальное видео с согласиями участников и экспертная оценка качества landmarks и интерпретации носителями казахского жестового языка.
- [ ] Репрезентативный независимый holdout; пороги кандидата, ручное принятие/откат активной модели, наблюдение ошибок и стоимости GPU/CPU.
- [ ] Vercel preview, `pwa` Root Directory с доступом к исходным файлам корня, backend HTTPS/CORS, разрешённые callback origins и отсутствующие в bundle секреты.
- [ ] Проверка установки и обновления на реальных Android/iOS устройствах; экранная клавиатура, плохая сеть, доступность, privacy notices и удаление/освобождение офлайн-хранилища.
- [ ] Проверить, что удаление исходника реально оставляет воспроизводимый массив после восстановления на другом диске; локальная копия рядом с SQLite резервным копированием не считается.

До выполнения этих пунктов стенд не следует открывать как публичную службу сбора пользовательских данных.
