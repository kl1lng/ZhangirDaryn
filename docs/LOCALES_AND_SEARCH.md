# Языки PWA и поиск казахской латиницей

Новый посетитель получает интерфейс на казахском языке (`kk`). Переключатель
«Қазақша / Русский / English» находится в верхней панели и доступен на телефоне.
Выбор сохраняется в браузере (`dosym-locale`) и применяется при следующем открытии,
включая автономный офлайн-экран. Смена языка не сбрасывает текст, выбранный файл
или согласия. Имена, названия жестов, комментарии и сами координаты не переводятся.

Основные модули:

- `pwa/features/locale.tsx` — язык, переключатель и React context.
- `pwa/lib/messages.json` — переводы интерфейса, сообщений, статусов и согласий; `messages.ts` экспортирует их в приложение.
- `pwa/lib/i18n.ts` — подстановка переводов и параметров.
- `pwa/scripts/prepare-locales.mjs` — словарь для статического офлайн-экрана;
  вызывается из подготовки ресурсов перед dev/build. Результат генерируется,
  вручную `public/offline-locales.js` не редактировать.
- `pwa/lib/gesture-search.ts` — единый поиск переводчика и словаря.

## Как находятся будущие слова и буквы

Поисковые ключи вычисляются из каждого названия, полученного из каталога.
Список отдельных замен для «Сәлем» не используется: новая запись получает
ту же поддержку автоматически после загрузки обновлённого каталога.
Поддерживаются кириллица, регистр, Unicode-диакритика и распространённые латинские
диграфы. Примеры: `Сәлем / sälem / salem`, `Жаңа / jaña / jaŋa / zhanga`,
`Қалай / qalai / qalay`, отдельные `Ә / ä`, `Ө / ö`, `Ш / ş / sh`.

Сначала учитывается точное исходное написание, затем латинская запись. Упрощённая
ASCII-запись может терять различия: `Ар` и `Әр` дают ключ `ar`. В такой ситуации
приложение предлагает выбор и не отправляет оба жеста в проигрыватель автоматически.
Несколько записей одного названия не означают несколько повторов одного жеста.
Для фразы выбирается наиболее длинная известная последовательность слов;
отсутствующие слова перечисляются отдельно. Английское слово `hello` не является
латинским написанием казахского слова «Сәлем» и не переводится этим механизмом.

## Алфавитная основа и пределы

Государственное описание усовершенствованного варианта алфавита приводит
`ә→ä`, `ө→ö`, `ү→ü`, `ұ→ū`, `ғ→ğ`, `ш→ş`:
[gov.kz — заседание Национальной комиссии](https://www.gov.kz/org/mfa-omsk/press/news/details/153331).
В документе описан вариант с 31 символом. Это не означает взаимно однозначного
соответствия всем 42 кириллическим буквам. DosYm использует централизованную
таблицу поисковой совместимости; `ñ/ŋ` и упрощённые диграфы принимаются как варианты
ввода. Это не автоматическая реформа орфографии и не перезапись исходных меток.
Неоднозначные буквы, например `h` для «х/һ», требуют выбора при наличии обеих записей.

Проверки: `gesture-search.test.ts` охватывает все 42 исходные буквы и произвольные
новые слова, фразы и коллизии; `i18n.test.ts` проверяет полноту статических переводов;
`locales.spec.ts` — выбор языка, сохранение состояния формы, латинский поиск,
неоднозначность и офлайн-экран.
