# DosYm PWA: ход локальной реализации

**Дата:** 29 октября 2026. **Ветка:** `codex/dosym-pwa`. **Состояние:** локальный MVP запущен; вход Google проверен end-to-end на локальном callback.

Пользователь разрешил локальную разработку и интернет-поиск. Push, публикация, изменение Google/Vercel/DB облаков и работа с реальными пользовательскими роликами в это разрешение не включались.

## Что уже работает локально

- Готовый клип «сәлем» явно перенесён из авторской базы в PWA: 56 кадров, 24 FPS, руки и корпус. Видео осталось в исходном проекте; обучение и исследования для импортированной записи выключены. Команда и ограничения — `docs/IMPORT_MOTION.md`.
- Из переданной SQLite локально импортированы ещё 114 клипов с подтверждёнными правами и достаточным трекингом рук (53 названия). Всего в PWA 115 импортированных клипов, включая исходный «сәлем». Все массивы проверены и имеют локальные backup-артефакты. Обучение/исследования выключены; видеоролики остались в `data/data/` и не попадали на Drive/GitHub/Vercel. Отчёт и повторяемая команда — `docs/IMPORT_MOTION.md`.
- Устранена потеря события готовности iframe при быстрой загрузке сцены: PWA проверяет уже загруженный документ и обрабатывает `load`. Проверка воспроизведения без одноразового сообщения `avatar-ready` включена в Playwright.

- Адаптивная Next.js PWA оболочка, перевод/поиск по имеющемуся словарю, 3D-аватар DosYm, карточка жеста, манифест установки и офлайн-пакет выбранного публичного жеста.
- Вход настраивается переключателем backend `DOSYM_AUTH_PROVIDER`: сохранён Supabase PKCE и добавлен direct Google OAuth через FastAPI; вход запрашивает только `openid email profile`. Для разработки используется локальный callback, credentials находятся в исключённом `backend/.env.local`.
- Python FastAPI, SQLite и файловое локальное хранилище; авторизация, проверка server-side ролей, пользовательские материалы и приватный доступ.
- Видеозагрузка порциями напрямую к Python API, техническая валидация/декодирование, статусы и повтор; видео не пересылается через Vercel функцию.
- Обычная загрузка ожидает модерации; тестовый модератор загружает без отдельного решения; одобрение создаёт одну задачу extraction.
- Разрешения на отображение, обучение и исследования запрашиваются отдельно. Обучение и исследования выключены по умолчанию; старые записи получают `research=0`; полный отзыв материала выключает оба разрешения.
- Переиспользуется `src.motion_db`/MediaPipe pipeline. Сжатый float32-массив landmarks, метаданные, версия и контрольная сумма хранятся отдельно от исходного файла; массив пригоден после удаления источника.
- Сервис умеет Drive resumable storage и PostgreSQL адаптер/миграцию, но они ещё не прошли реальный integration test.
- Успешная обработка может поставить пакетный запуск обучения; отдельный TensorFlow trainer сохраняет checkpoint-кандидат и метрики. Он не заменяет авторскую модель/активную модель.
- Отзыв материала скрывает его из каталога и новых обучающих наборов, не уничтожая координаты/исходник. Ошибка извлечения сохраняет видео и даёт повтор.
- Локальный запуск и остановка через `scripts/start-pwa.ps1`, `scripts/stop-pwa.ps1`; подробные шаги — в `pwa/README.md`.

## Известные границы

- Google OAuth consent screen и web client подготовлены; владелец добавлен в список test users, локальный callback прошёл полный вход и вернул роль модератора из server-side настройки. При тесте вход запросил только имя/фото профиля и почту. Тестовая учётная запись пока не публична: приложение остаётся в режиме Testing. Drive OAuth/folder/refresh token, реальный PostgreSQL, хостинг worker и Vercel production не настроены.
- Локальная файловая копия координат находится рядом с локальной SQLite и не переживёт потерю диска. Production deletion требует внедрённой резервной копии и восстановления; сейчас удаление в production-контуре намеренно закрыто.
- Текущий Drive adapter ожидает выделенные серверные OAuth credentials к закрытой Drive папке. Он не авторизует автоматическую запись в личный Drive каждого участника.
- Local test uploads are technical fixtures only. Demo role check is not Google auth/security proof for public release.
- Автоматический extraction landmarks — не автоматическое доказательство корректного жеста. Training smoke-test — синтетический пример, не мера качества распознавания КЖЯ.
- Нет проверенной независимой валидации кандидата, active model registry, подтверждения публикации и rollback. Общая рабочая модель не переключается автоматически.
- Интерфейс PWA по умолчанию на казахском, с русским и английским переключателем; выбор сохраняется и действует офлайн. Названия жестов сохраняют исходное написание. Поиск кириллицей/латиницей применяется ко всем меткам каталога; правила и источники — `docs/LOCALES_AND_SEARCH.md`.
- Research consent сохраняется раздельно, однако экспорт/аналитика для исследовательских наборов и выборочный отзыв одного разрешения пока не реализованы.
- Нужны устройства iOS/Android, screen reader/keyboard/200% zoom, политика хранения/удаления для публичных участников, публичный HTTPS/CORS и реальная проверка backup/restore.

## Оптимизация сайта (29 октября 2026)

- Renderer аватара больше не держит постоянный render-цикл: сцена рисуется по запросу и во время движения. Скрытая вкладка и iframe вне экрана останавливают RAF; возврат на экран сам не продолжает жест.
- Подготовка движения выполняется порциями по два кадра и отменяется при выборе нового движения. Синхронный и асинхронный результаты сравниваются тестом; массив координат и исходный FPS не меняются.
- До выбора жеста React показывает статичную заглушку; iframe и Rocketbox GLB загружаются только при необходимости.
- Экран загрузки и модули материалов вынесены в отдельные динамические chunks. Supabase SDK загружается по требованию только в провайдере Supabase; прямой Google/VPS режим его не запрашивает.
- PWA и автономная HTML-страница используют CSS-гарнитуру `sans-serif`. Noto-файл остался в репозитории как лицензированный источник, но приложение его не запрашивает.
- Лабораторный Edge профиль в `data/pwa/performance/` после изменений: LCP 524 мс, первый экран без iframe и без загрузки webfont, около 852 КБ суммарного dev-трафика; 56 кадров при 24 FPS. В покое и во время паузы RAF-прирост равен нулю; максимальная измеренная порция подготовки — 6,6 мс, iframe long task — 55 мс. Это локальный headless/dev замер без ограничения сети, не результат на телефоне и не Core Web Vitals реальных посетителей.
- Production-проверки после изменений: сборка успешна, PWA typecheck успешен, 9 браузерных сценариев locale/offline/playback прошли. Включение/выключение реального Google-входа и полный пользовательский workflow загрузки не проверялись на production preview.
- Импорт набора (29 октября): пакетный просмотр откобрал 114/249 клипов по явным флагам качества и прав; 134 не прошли порог видимости рук, 3 имеют `rights_confirmed=false` (2 пересекаются с предыдущей группой). SQLite источника открывалась read-only; записи назначения и 115 NPZ-backup артефактов проверены по контрольной сумме. API отдаёт 115 клипов, интерфейс показывает 53 уникальных названия без дублей. В локальном dev проверено реальное воспроизведение импортированного 38-кадрового клипа `Ё`. PWA unit — 10 passed, импортер — 5 passed, typecheck/build успешны. Видеофайлы (254 файла, около 194 МБ) сохранены на месте; у одного знака и четырёх слов нет пригодного клипа. Данные не коммитились и не публиковались.

План и оставшиеся задачи: `docs/superpowers/plans/2026-10-29-dosym-performance.md`.

## Проверки

Локализация и латинский поиск (29 октября): 9 PWA unit-проверок, 12 браузерных сценариев, 35 исходных JS-проверок и 112 Python-проверок (одна необязательная пропущена) прошли. TypeScript и production build успешны. Проверены все 42 кириллические буквы, произвольные новые слова, диакритика, ASCII-коллизии, сохранение языка и значений формы. Визуально проверены 12 сочетаний языка и ширины (320/390/768/1440 px), фактическое проигрывание `salem → сәлем` и офлайн-экран. Полный сценарий тестовых видео-загрузок не запускался на рабочей локальной базе с Google-входом.

Исправление «Сәлем» (29 октября): 112 Python-проверок — успешно, одна необязательная TensorFlow-проверка пропущена; 35 исходных JS-проверок, две PWA unit-проверки и новая Playwright-проверка готовности iframe прошли. PWA typecheck и production build успешны. Реальное воспроизведение проверено в браузере с исходными 56 кадрами: движение дошло до середины, пауза сработала. Полный PWA suite с тестовыми загрузками не запускался на рабочей локальной базе с Google-входом.

Исходный проект до auth изменений: 100 Python тестов (99 passed, 1 optional TensorFlow case skipped), 35 JS тестов, 2 PWA unit tests, 9 PWA Playwright tests; typecheck и build проходили. После auth изменений Python compileall и PWA typecheck прошли; suite tests не запускался. Локальный браузерный вход Google прошёл успешно.

Технический визуальный прогон Microsoft Edge прошёл без JS ошибок и горизонтального overflow на 320/390/768/1440 px; реальный Rocketbox canvas загрузился. Скриншоты находились в исключённой из Git `pwa/test-results/visual/`. Это не приёмка настоящих телефонов и screen reader.

Одно предупреждение MediaPipe о fallback feedback tensor встречалось при загрузочном тесте; оно не сорвало декодирование и не меняет статус теста.
