# Как показать коллекцию «Орыс ым тілі» (РЖЯ, Slovo) на сайте

Коллекция не входит в репозиторий (65 МБ). Сайт показывает её только если задан адрес `NEXT_PUBLIC_RSL_LIBRARY_URL`.
Без него (так сейчас в Production) ничего не меняется.

## 1. Подготовить данные (уже сделано локально)
Папка `data/slovo/export/rsl` (1000 жестов + `catalog.json` + `ATTRIBUTION.md`) создаётся командой:

```bash
.venv-pwa/Scripts/python.exe scripts/slovo_export.py
```

## 2. Загрузить в хранилище
В панели Supabase: Storage, бакет `gesture-library`, создать папку `rsl-20261104`, загрузить в неё все файлы
из `data/slovo/export/rsl` (около 1002 файлов, 65 МБ). Бакет публичный, как для основной библиотеки.

## 3. Включить на сайте
В Vercel (проект dosym, Settings, Environment Variables, Production) добавить:

```
NEXT_PUBLIC_RSL_LIBRARY_URL=https://aiehxwknetwvboozjftn.supabase.co/storage/v1/object/public/gesture-library/rsl-20261104
```

и сделать Redeploy. В словаре появится выбор «Ым тілі», на странице «О материалах и данных» раздел «Источники данных»
с указанием авторов Slovo и лицензии.

## 4. Условия
- Лицензия Slovo: публичная лицензия с указанием авторства и сохранением условий (вариант CC BY-SA 4.0); текст лежит в
  `data/slovo/license_en_us.pdf`. Прочитайте страницы 4–5 целиком перед публикацией.
- Это русский жестовый язык, не казахский, не проверен носителями. Предупреждения в интерфейсе нужно сохранять.
- Чтобы убрать коллекцию: удалить переменную в Vercel и сделать Redeploy.
